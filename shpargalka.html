Шпаргалка

Сабактарда колдонулган эң негизги HTML тегдер, CSS касиеттери, JavaScript синтаксиси жана Git буйруктары — бир баракта.

📘 HTML: негизги тегдер

ТегЭмне үчүн
<div>Жалпы контейнер, блок деңгээлинде
<span>Жалпы контейнер, текст ичинде (inline)
<p>Абзац (параграф)
<h1>…<h6>Аталыштар, h1 эң чоңу
<a href="">Шилтеме (link)
<img src="" alt="">Сүрөт; alt — жүктөлбөсө көрүнүүчү текст
<ul>/<ol>/<li>Тартипсиз/тартиптүү тизме жана элементи
<button>Баскыч
<input>Форма талаасы (текст, сан, чекбокс ж.б.)
<form>Форма — бир нече input'ту бириктирет
<table>/<tr>/<td>/<th>Таблица, сап, клетка, баш клетка
<script src="">JS файлын HTML'ге кошуу

КасиетЭмне үчүн

background-colorФондун түсү

display: grid / grid-template-columnsТор (grid) макет жана мамычалары
gapЭлементтердин арасындагы боштук
width / heightТуурасы / бийиктиги
font-size / font-weightТамганын өлчөмү / калыңдыгы
text-alignТексттин горизонталдык жайгашуусу
position (relative/absolute/fixed)Элементти жайгаштыруу ыкмасы
transitionКасиет өзгөргөндө жумшак анимация
box-shadowКөлөкө
cursor: pointerКурсорду баскыч сымал көрсөтүү

КодЭмне кылат

function name() {} / () => {}Функция / arrow-функция
if / elseШарт менен код бутактоо
for / whileЦикл — кодду кайталоо
array.map()Ар бир элементти өзгөртүп, жаңы массив кайтарат
array.filter()Шартка ылайык элементтерди тандайт
array.forEach()Ар бир элемент үчүн код аткарат

console.log()Консолго маалымат чыгаруу
document.querySelector()CSS-селектор боюнча элемент табуу
element.addEventListener()Элементке окуя (click ж.б.) кошуу
localStorage.setItem() / getItem()Браузерде маалымат сактоо / окуу
